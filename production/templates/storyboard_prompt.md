# 分镜拆解提示词（发给 Claude 用）

> 用法：把下面整段提示词 + 你的剧本全文，一起发给 Claude。
> 得到的结果存为 `03_storyboard/storyboard.md`。

---

请把下面的剧本拆解为动画分镜表。要求：

1. 每个镜头时长 5~10 秒（图生视频工具单次生成的上限），台词长的拆成多个镜头。
2. 全片控制在 ___ 个镜头以内（按总时长 ÷ 7秒 估算）。
3. 注意视听语言：景别要有变化（全景交代环境 → 中景对话 → 特写情绪），避免连续同景别。
4. 每个镜头按下面的表格输出：

| 字段 | 说明 |
|---|---|
| 镜头编号 | shot_01、shot_02… |
| 时长 | 秒数 |
| 景别 | 远景/全景/中景/近景/特写 |
| 画面内容 | 一句话描述画面里发生什么 |
| 台词/音效 | 这个镜头里的台词（标注角色名）或音效 |
| 出图提示词 | 给文生图工具的中文提示词：固定开头"日系动漫风格，赛璐璐上色，"+ 角色外貌关键词 + 场景 + 构图/景别 + 光线氛围 |
| 运动提示词 | 给图生视频工具的提示词：描述画面中的运动（角色动作、镜头推拉摇移），保持简短，一次只描述 1~2 个运动 |

5. 最后附一个"角色提示词速查表"：每个角色一行完整的外貌提示词，方便我出图时复制。
