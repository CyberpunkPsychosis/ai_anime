# 无 AI 的可控动漫制作流程（个人创作者）

> 适用前提：放弃 AI 生成（抽卡=不可控），你自己做**剧本、台词、分镜、剪辑**，
> 需要确定的是中间的"视觉动画"怎么做。本文给出可控、确定性的方案。
> 仓库里已有的剧本/分镜（`episodes/ep01/`）这套素材，换任何视觉方法都能复用。

## 核心矛盾：控制力 ↔ 工作量

| 方法 | 控制力 | 工作量 | 要会画画 | 适合 |
|---|---|---|---|---|
| 动态漫 / Motion Comic | 高 | 最低 | 要（或买图/委托） | 对话向、漫剧 |
| **2D 骨骼动画** | 高 | 中 | 要画一次 | **对话向短片首选** |
| 三渲二 3D | 极高 | 前期重后期轻 | **不用会画** | 运镜/动作/系列复用 |
| 全手绘逐帧 | 最高 | 最高 | 要很会画 | 追求作画质感 |

## 决策分岔：你会画画吗？

- **会画** → 2D 骨骼动画（角色画一次，绑骨骼，动骨骼+换口型表情）
- **不会画** → 三渲二 3D（VRoid 捏角色，零绘画基础；Blender 卡通渲染+动画）

---

## 管线 A：2D 骨骼动画（会画画 / 对话向首选）

**整体思路**：每个角色只画一次（分图层）→ 绑定 → 动画靠操控骨骼 + 口型/表情切换。
确定性强、改哪动哪、无抽卡。对话戏（动作少、重表情口型）效率极高。

| 环节 | 工具 | 说明 |
|---|---|---|
| 剧本/台词 | 你（可让我帮你打磨） | 已有 `01_script/script.md` |
| 分镜 | 你（已有 `03_storyboard/`） | 直接复用 |
| 角色设计/作画 | **CLIP STUDIO PAINT**（业界标准作画软件） | 角色分图层画（身体/头发/眼睛/嘴/手分开） |
| 绑定+动画 | **Live2D Cubism**（VTuber式、上半身对话）或 **Cartoon Animator**（全身2D纸偶，**能根据配音自动生成口型**） | Cartoon Animator 的 AccuLips 对漫剧最省事 |
| 配音 | 你自己录 / 找配音 | 录好导入做口型 |
| 背景 | CLIP STUDIO 画 / 买素材 | 单场景只需一两张 |
| 剪辑/运镜/字幕 | **剪映** 或 **DaVinci Resolve**（免费） | 拼镜头、加 BGM、字幕、转场 |

**学习曲线**：CLIP STUDIO 几天上手，Live2D/Cartoon Animator 一两周。
**首选推荐**：对话向短片用 **Cartoon Animator**——导入立绘、配音自动对口型、做表情动作，是这条路里最快出片的。

## 管线 B：三渲二 3D（不会画画 / 想要运镜与系列复用）

**整体思路**：3D 建模角色一次，绑骨骼，K 动画，卡通材质渲染成"看起来像 2D 动漫"。
角色可反复用、镜头可自由推拉摇移、做多集成本递减。**不需要绘画功底。**

| 环节 | 工具 | 说明 |
|---|---|---|
| 角色建模 | **VRoid Studio**（免费） | 捏脸式做日系3D角色，零基础，导出 .vrm |
| 动画/渲染 | **Blender**（免费） | 导入角色，搭卡通(三渲二)材质，K 动作，渲染 |
| 现成动作 | **Mixamo**（免费动作库）/ **MMD** 动作 | 走路、转身等套用，不用全手 K |
| 口型 | Blender 形态键（shape key）按音频 K | 或用 VTuber 工具录面捕 |
| 场景 | Blender 搭 / 买模型 | 教室等场景可复用 |
| 剪辑 | 剪映 / DaVinci Resolve | 同上 |

**学习曲线**：VRoid 一两天；Blender 是大头，三渲二+动画要 2-4 周入门，但天花板高、可持续。

## 管线 C：动态漫（最省力，想先快速出东西）

静态立绘 + 镜头运动（推拉摇移）+ 配音 + 字幕 + 最小口型闪动。本质是"手动漫剧"。
- 出图：CLIP STUDIO 画 / 委托画师 / 买立绘
- 制作：After Effects 或剪映，做运镜、图层动、口型闪
- 最适合先用最低成本把《放学后的橡皮》做出一版，验证剧本和节奏。

## 不变的两头（你已经在做的）

- **前期**：剧本、台词、分镜——这是片子的灵魂，已有成果，任何视觉方法都复用。
- **后期**：剪辑、配音、BGM、字幕——剪映（易）或 DaVinci Resolve（免费、专业）。

## 给《放学后的橡皮》的具体建议

这片子是双人教室对话、动作极少、重表情口型：
1. **想最快出片 + 会一点画** → **Cartoon Animator**（管线 A）：配音自动对口型，对话戏最快。
2. **不会画画** → **VRoid + Blender 三渲二**（管线 B）：捏两个女生 3D 角色，搭个教室，K 简单动作。
3. **想先验证节奏** → 先做**动态漫**（管线 C）一版，再升级到 A 或 B。

> 共同点：都没有抽卡，每一帧都是你定的；技能会随练习累积，作品质量稳定可控——
> 这正是 AI 生成给不了的。
