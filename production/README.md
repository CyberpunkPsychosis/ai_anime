# AI 动漫制作流程（个人创作者版）

目标：一个人 + AI 工具，做出"日式动漫风"的短篇动画（漫剧 / 短番 / PV）。

## 为什么不用工作流平台（n8n / ComfyUI / Coze）

这条管线里最贵的环节是**图生视频**（按次/按秒计费），而 AI 出图出视频都要"抽卡"——
每一步都需要你人工挑选满意的结果再进入下一步。全自动工作流会把不满意的中间产物
也自动送去生成视频，白白烧钱。所以正确的形态是：

> **半自动管线**：每个环节用模板规范输入输出，人在环节之间做质检和筛选。

等以后要量产（比如一周一集），再考虑接 API 自动化，到时候在 `scripts/` 里加就行。

## 七步流程总览

| 步骤 | 做什么 | 用什么工具 | 产出放哪 |
|---|---|---|---|
| 1. 剧本 | 和 Claude 对话写剧本 | Claude（对话） | `episodes/epXX/01_script/` |
| 2. 角色设定 | 生成角色立绘/三视图 | 即梦 / Midjourney / NovelAI | `episodes/epXX/02_characters/` |
| 3. 分镜表 | 把剧本贴给 Claude 拆成分镜 | Claude（用 `templates/storyboard_prompt.md`） | `episodes/epXX/03_storyboard/` |
| 4. 首帧图 | 按分镜逐镜头出图 | 即梦 / 海艺（垫角色参考图保证一致性） | `episodes/epXX/04_frames/` |
| 5. 视频片段 | 首帧图 → 5~10 秒动画 | 可灵 / Vidu / AniSora / Animon | `episodes/epXX/05_clips/` |
| 6. 配音 BGM | 台词配音 + 口型 + 音乐 | 剪映 AI 配音 / 海螺 TTS | `episodes/epXX/06_audio/` |
| 7. 剪辑成片 | 拼接、调速、字幕 | 剪映（精剪）/ `scripts/assemble.py`（快速预览） | `episodes/epXX/07_final/` |

## 每一步的关键要点

### 1. 剧本（Claude 对话）
- 用 `templates/script_template.md` 的结构来要求 Claude 输出。
- 短片建议 1~3 分钟、单场景冲突、2~3 个角色以内——角色越多，一致性越难保。

### 2. 角色设定（最影响成片质量的一步）
- 每个角色出一张**正面半身立绘 + 三视图**，背景纯色。
- 文件命名：`角色名_pose.png`，例如 `xiaoyu_front.png`。
- 之后所有出图都必须垫这张参考图（即梦"参考人物"、海艺"角色一致性"功能）。
- 同时把角色的文字设定（发色、瞳色、服装细节）存成 `角色名.md`，出图提示词里每次都带上——双保险。

### 3. 分镜表（Claude 对话）
- 把剧本全文 + `templates/storyboard_prompt.md` 里的提示词一起发给 Claude。
- 得到的分镜表存为 `03_storyboard/storyboard.md`，这是后面所有步骤的施工图。

### 4. 首帧图
- 逐镜头用分镜表里的"画面提示词"出图，**垫角色参考图**。
- 一个镜头抽 3~5 张，挑最好的一张，命名 `shot_01.png`、`shot_02.png`…（编号对齐分镜表）。
- 不满意别将就——首帧图崩了，视频一定崩。

### 5. 图生视频
- 把首帧图 + 分镜表里的"运动提示词"喂给视频工具。
- 工具选择：
  - **可灵**：综合质量最好，运镜强，适合主力镜头
  - **Vidu**：物理动作自然，适合动作镜头
  - **AniSora**（B站开源，免费）：动漫风格最纯正，有 GPU 或用其在线服务可白嫖
  - **Animon**：日式美学，免费额度可做备选
- 命名 `shot_01.mp4`、`shot_02.mp4`…
- 省钱技巧：先用低分辨率/免费档全部跑一遍预览，确认节奏后只重生成关键镜头的高清版。

### 6. 配音 / BGM
- 台词逐句配音，命名 `shot_01_line1.mp3` 对齐镜头。
- 剪映自带 AI 配音 + 自动口型，对二次元角色效果够用。

### 7. 剪辑成片
- 快速预览：`python3 scripts/assemble.py episodes/ep01` 一键按编号拼接所有片段（需本机装 ffmpeg）。
- 精剪用剪映：转场、字幕、BGM、音画对齐。

## 新一集怎么开工

```bash
cp -r production/episodes/ep01 production/episodes/ep02   # 复制空目录结构
```

然后从第 1 步开始走流程即可。
